# Minesweeper

*Also known as: Sure Sweep*

**Encyclopedia ID 22341** (permanent) · https://bpupadhyaya.github.io/world-heritage-games-site/games/22341-minesweeper/

Minesweeper is a computer-age logic classic from the 1980s: a hidden field of mines must be cleared square by square using only the numbers revealed at each step.

## How it is played

from these counts the player deduces which neighbours are safe and marks the rest. Sure Sweep is the Arcforge version, built so that no board ever needs a guess.
