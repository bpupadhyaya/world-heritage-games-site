# Nail driving

*Hammerschlagen · Hammerschlagen / Wettnageln*

**Encyclopedia ID 82** (permanent) · https://bpupadhyaya.github.io/world-heritage-games-site/games/82-nail-driving/

![Nail driving](../../../img/photos/00082-nail-driving.jpg)
