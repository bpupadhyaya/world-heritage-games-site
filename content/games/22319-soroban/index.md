# Soroban

*Also known as: そろばん · Abacus · Japanese abacus*

**Encyclopedia ID 22319** (permanent) · https://bpupadhyaya.github.io/world-heritage-games-site/games/22319-soroban/

The soroban is the Japanese bead abacus: rods in a wooden frame, each carrying one five-bead above the beam and four one-beads below it, still taught to schoolchildren for fast arithmetic.

## How it is played

Each rod stands for one decimal place. A number is set by sliding beads toward the beam; adding and subtracting follow fixed finger movements that use the complements of five and ten, so long columns can be summed at speed. Trained users go on to anzan, picturing the beads and calculating entirely in the head.
