# Langeleik

*langeleik · Norwegian drone zither*

**Encyclopedia ID 1322** (permanent) · https://bpupadhyaya.github.io/world-heritage-games-site/games/1322-langeleik/

![Langeleik](../../../img/photos/01322-langeleik.jpg)
