# One Arrow Oath

**Encyclopedia ID 22334** (permanent) · https://bpupadhyaya.github.io/world-heritage-games-site/games/22334-one-arrow-oath/

One Arrow Oath is an Arcforge original inspired by a warrior's vow in ancient Sanskrit epic poetry: a single arrow, a long campaign and a fresh hand of choices on every attempt.

## How it is played

Each run strings together encounters from the campaign; the player builds a small deck of techniques and spends them wisely, because the one arrow may be loosed only once.

## Heritage note

An Arcforge original, created for the World Heritage Games collection rather than drawn from one tradition.
